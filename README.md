# SpeedBurguer 🍔

SpeedBurguer es un proyecto web enfocado en la venta de deliciosas hamburguesas, ofreciendo una interfaz moderna e intuitiva para que los usuarios puedan conocer los productos, explorar opciones y ponerse en contacto de manera sencilla.

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica de la página.
- **CSS3**: Diseño, estilos responsive y componentes visuales.
- **JavaScript**: Funcionalidad y dinamismo de la web.

## Características

- Panel de administración (`admin.html`) para gestión interna.
- Página de contacto (`contacto.html`) para comunicación con los clientes.
- Diseño enfocado en la experiencia de usuario (UX) y usabilidad.
