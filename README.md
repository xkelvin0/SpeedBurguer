# SpeedBurguer 🍔🍟

</p>

## 📖 Descripción del Proyecto

**SpeedBurguer** es una aplicación web desarrollada como proyecto final del curso **Marco de Desarrollo Web**. El objetivo principal de este sistema es ofrecer una experiencia de usuario (UX) ágil y atractiva, donde los clientes puedan explorar el menú de comida rápida, conocer los productos disponibles y contactarse de manera sencilla con el negocio.

Además, el proyecto contempla un área de administración, proporcionando una estructura base estructurada para gestionar el contenido de la plataforma de forma interna.

## ✨ Características Principales

- **Diseño Atractivo y Responsivo**: Interfaz gráfica amigable que se adapta a diferentes tamaños de pantalla utilizando CSS3.
- **Gestión Administrativa (`admin.html`)**: Interfaz dedicada para el control y la gestión interna de los recursos y pedidos de la tienda.
- **Página de Contacto (`contacto.html`)**: Sección interactiva con formulario para la comunicación directa con los clientes y la recepción de sugerencias.
- **Navegación Intuitiva**: Menús claros y accesibles pensados en la mejor experiencia para el usuario final.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido desde cero utilizando las tecnologías fundamentales para el desarrollo web frontend:

- **HTML5**: Para la estructura semántica, maquetado de las vistas y accesibilidad.
- **CSS3**: Para la estilización, variables de diseño, uso de flexbox/grid, animaciones y diseño adaptable (Responsive Design).
- **JavaScript (Vanilla)**: Para agregar interactividad, dinamismo a los componentes y validaciones en el lado del cliente.

## 🚀 Cómo ejecutar el proyecto localmente

Dado que es un proyecto frontend estático, la ejecución es muy rápida y no requiere instalación de dependencias complejas:

1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/xkelvin0/SpeedBurguer.git
   ```
2. Entra en el directorio del proyecto:
   ```bash
   cd SpeedBurguer
   ```
3. Abre cualquiera de los archivos HTML (como `admin.html` o `contacto.html`) haciendo doble clic sobre él para abrirlo en tu navegador web de preferencia (Google Chrome, Firefox, Edge). 
4. *Opcional:* Si usas Visual Studio Code, puedes abrir el proyecto e iniciar la extensión **Live Server** para una experiencia de recarga automática al hacer cambios.
